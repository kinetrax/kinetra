# KinetraX Website

Blockchain-powered sport marketplace website.

## Local Development

Install dependencies:

```bash
npm install
```

Run a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

## Project Structure

- `index.html` - Main homepage
- `whitepaper.html` - Whitepaper page
- `privacy-policy.html` - Privacy policy page
- `terms-of-use.html` - Terms of use page
- `css/` - Stylesheets
- `js/` - JavaScript files
